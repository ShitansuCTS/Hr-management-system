# Permissions

The following table outlines the access permissions for each user role in the HRMS Portal.

| Module                  | HR Administrator | Employee         |
| ----------------------- | ---------------- | ---------------- |
| Dashboard               | ✅                | ✅                |
| Organization Management | ✅                | View Only        |
| Employee Management     | ✅                | View Own Profile |
| Attendance              | ✅                | View Own         |
| Leave Management        | ✅                | Apply & View     |
| Company Calendar        | ✅                | View             |
| Activity Management     | ✅                | View             |
| Payroll                 | ✅                | View Own         |
| Reports                 | ✅                | ❌                |
| Settings                | ✅                | ❌                |

## Summary

Permissions are managed based on user roles to ensure secure access to the application's features and data.
