# 01 - Requirements

This section defines the business requirements of the HRMS Portal. It provides an overview of the application's modules, the different user roles, and the permissions assigned to each role.

## Documents

| File             | Description                                                   |
| ---------------- | ------------------------------------------------------------- |
| `modules.md`     | Lists all modules available in the HRMS Portal.               |
| `user-roles.md`  | Describes the different user roles within the application.    |
| `permissions.md` | Defines the permissions and access levels for each user role. |

## Purpose

The purpose of this section is to provide a clear understanding of what the application should do, who will use it, and the level of access available to each role before moving on to the technical implementation.
