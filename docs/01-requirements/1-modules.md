# Application Modules

This document provides an overview of the core modules available in the HRMS Portal. Each module is designed to manage a specific business function within the organization.

---

## 1. Organization Management

This module is used to manage the organization's structure, including departments, designations, and job roles.

### HR/Admin

* Create and manage departments
* Create and manage designations
* Configure job roles
* Maintain organization structure

### Employee

* View assigned department
* View assigned designation
* View job role

---

## 2. Activity Management

This module is used to share company updates, announcements, and important notifications.

### HR/Admin

* Create announcements
* Share company updates
* Notify all or selected employees
* Manage activity history

### Employee

* View announcements
* Read company updates
* Stay informed about organization activities

---

## 3. Leave Management

This module manages employee leave requests and leave balances.

### HR/Admin

* View all leave requests
* Approve or reject leave
* Add comments
* Manage employee leave balances
* Track leave reports

### Employee

* Apply for leave
* View leave history
* Check leave balance
* Track leave request status

---

## 4. Company Calendar

This module manages holidays, events, and attendance in a calendar view.

### HR/Admin

* Create company holidays
* Manage company events
* View employee attendance
* Monitor leave calendar

### Employee

* View company holidays
* View approved leaves
* Check attendance calendar
* Stay updated with company events

---

## 5. Authentication

This module provides secure access to the HRMS Portal.

### HR/Admin

* Login securely
* Reset password
* Access administrative dashboard

### Employee

* Login securely
* Reset password
* Access employee dashboard

---

## 6. Employee & User Management

This module manages employee records and user profiles.

### HR/Admin

* Add new employees
* Update employee information
* Manage employee profiles
* Manage payroll details
* Manage employee documents
* View employee records

### Employee

* View personal profile
* Update permitted information
* View payroll information
* View personal documents
* View leave and attendance details

---

## 7. Dashboard

The dashboard provides role-based insights and quick access to important information.

### HR Dashboard

* Employee statistics
* Today's attendance
* Employees on leave
* Upcoming holidays
* Monthly leave summary
* Recent activities
* Company announcements

### Employee Dashboard

* Personal attendance
* Leave balance
* Pending leave requests
* Approved leaves
* Upcoming holidays
* Recent announcements
* Personal profile summary

---

## Summary

The HRMS Portal follows a modular architecture where each module serves a specific business purpose. Access to each module is controlled through role-based permissions, ensuring that HR administrators and employees can only perform actions relevant to their responsibilities.
